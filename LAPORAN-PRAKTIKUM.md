## Dasar Teori
Searching dalam Singly Linked List berarti mencari tahu apakah suatu elemen (key value) tertentu terdapat dalam daftar atau tidak, dan jika terdapat, menentukan posisinya. Karena Singly Linked List tidak mendukung random access, pencarian dilakukan dengan sequential traversal yang dimulai dari HEAD node[1].

### A. Definisi dari Searching<br/>
Searching adalah proses menemukan sebuah node tertentu dalam Linked List dengan membandingkan key yang diberikan dengan data yang tersimpan di setiap node. 
Searching akan terus berlanjut hingga:
#### 1. Elemen tersebut telah ditemukan, atau.
#### 2. Telah mencapai akhir daftar (NULL)[1].

### B. Keunggulan Searching dalam Linked List<br/>
Manfaat:
#### 1. Implementasinya Simpel.
#### 2. Tidak perlu data yang sudah diurutkan.
#### 3. Dapat digunakan untuk ukuran data yang dinamis[1].

void insertLast(linkedlist &List, address nodeBaru) {
    if (isEmpty(List)) {
        List.first = nodeBaru;

        address nodeBantu = List.first;

            nodeBantu = nodeBantu->next;
        }
        nodeBantu->next = nodeBaru;

        cout << "List kosong!" << endl;

}

void delLast(linkedlist &List){
    address nodeHapus, nodePrev;

        nodeHapus = List.first;
        if(nodeHapus->next == Nil){
            List.first->next = Nil;
            dealokasi(nodeHapus);

    } else {
        cout << "list kosong" << endl;
    }
}

void delAfter(linkedlist &List, address nodeHapus, address nodePrev){
    if(isEmpty(List) == true){
        cout << "List kosong!" << endl;

        if (nodePrev != Nil && nodePrev->next != Nil) { 
            nodeHapus = nodePrev->next;

            nodeHapus->next = Nil;         
            dealokasi(nodeHapus);

void FindNodeByData(linkedlist list, string data){
    if(isEmpty(list) == true){
        cout << "List kosong!" << endl;
    } else {
        address nodeBantu = list.first;
        int posisi = 0;
        bool found = false;
        while(nodeBantu != Nil){
            posisi++;
            if(nodeBantu->isidata.nama == data){
                cout << "Data " << data << " ditemukan pada posisi ke-" << posisi << "!" << endl;
                cout << "Nama Buah : " << nodeBantu->isidata.nama << ", Jumlah : " << nodeBantu->isidata.jumlah << ", Harga : " << nodeBantu->isidata.harga << endl;
                found = true;
                break;
            }
            nodeBantu = nodeBantu->next;
        }
        if(found == false){
            cout << "Node dengan data " << data << " tidak ditemukan!" << endl;
        }
    }
    cout << endl;
}
